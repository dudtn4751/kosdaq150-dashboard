# 수출·산업 모멘텀 스코어 — 개발 핸드오프 (최종본)

> **목적**: 수출입(+산업) 데이터로 **기업 실적을 선행하는 섹터별·기업별 점수**를 산출. 기존 `calc_data_score`·대시보드 `signal_score`를 대체·통일.
> **철학**: 수출액의 "수준"이 아니라 모멘텀의 **방향·속도·가속·품질**을 산다(EPS 리비전과 동일 철학).
> **v1**: 수출(실측)로 완성. 산업 데이터는 seam(None 허용)으로 연결 지점만.

---

## 0. 입력 데이터 (이미 존재)

- `trade_utils_data.py`
  - `compute_item_metrics(df)` — 품목별: yoy, mom, price_yoy, volume_yoy, ma3_yoy, **ma3_yoy_prev**(가속용)
  - `compute_company_metrics(df)` — (품목,기업)별 동일 지표. **기업 실측 수출**(`company_trade_history_long.csv`)
- `item_mapping.csv` — 품목↔기업. `HS_MAP`(backend) — 기업↔수출 노출.
- `epsrev/data/industry.py get_industry_data()` — 산업 데이터(현재 스텁).

## 1. 측정 4축 (품목·기업 각 시리즈)

| 축 | 정의 | 의미 |
|---|---|---|
| 모멘텀 `C_mom` | ma3_yoy(3개월 평균 YoY) | 성장 국면 |
| 가속 `C_acc` | `accel = ma3_yoy − ma3_yoy_prev` + trough_rebound(음수 저점 통과 후 개선) | ★개선의 가속·사이클 전환 |
| 품질 `C_qual` | volume_yoy 우세 → 가점 / price_yoy 우세 → 감점 | 물량(진짜) vs 단가(착시) |
| 사이클/추세 `C_cyc` | runrate_gap = 최근 수출 / 장기추세(24M 평균) − 1 | 사이클·추세 대비 위치 |

### ★ 시리즈 타입 (series_type) — 지표마다 다르게 처리
각 지표는 config에 `series_type`를 갖는다:
- **growth형** (수출·판매·생산량 등 "양"): 위 4축 그대로 (YoY·가속·품질 물량/단가).
- **level형** (금리·유가·정제마진·신조선가·스프레드·BDI 등 "가격/수준"): 
  - 모멘텀 `C_mom` = 레벨의 z((x − median)/MAD) 또는 Δ(전월 대비 변화)
  - 가속 `C_acc` = 레벨의 2차 차분
  - **품질 `C_qual` 제외**(가격엔 물량/단가 개념 없음 → 가중제외 재정규화)
  - 사이클 `C_cyc` = 레벨 vs 24M 추세 위치
  - ⚠️ level형에 YoY-성장률 로직 쓰지 말 것(레벨의 YoY%는 왜곡).
- **모든 시계열은 계산 전 월간 리샘플**(일/주간 BDI·SCFI 등 → 월평균 또는 월말)로 주기 통일.

## 2. 정규화 (섹터 규모·특성 차이 흡수)

### ① 자기 이력 표준화 (robust z)
각 축을 그 시리즈 **자기 역사** 기준으로 표준화:
```
z = clip( (x − median_hist) / MAD_hist , −3, +3 )   # winsorize
```
→ 반도체(±80%)·화장품(±15%)이 같은 스케일. 규모·변동성 흡수.

### ② 섹터 특성 자동 가중 (데이터 기반, 수동 라벨 없음)
섹터 과거에서 3통계 측정:
```
ρ = clip( autocorr(ma3_yoy, lag=3), 0, 1 )                  # 지속성/사이클성
π = Var(price_yoy) / ( Var(price_yoy) + Var(volume_yoy) )   # 단가 주도성
σ = MAD(ma3_yoy) 를 전 섹터 대비 min-max 0~1 정규화          # 변동성
```
가중(정규화 전 → Σ=1로 정규화). α,β,γ,δ는 전 섹터 공통 튜닝상수:
```
w_acc  = 0.30 · (1 + 0.6·ρ + 0.3·σ)
w_cyc  = 0.20 · (1 + 0.5·ρ)
w_qual = 0.20 · (1 + 0.8·max(0, π−0.5)·2)
w_mom  = 0.30 · (1 − 0.3·σ)
```
사이클형→가속·사이클 강조, 원자재형→품질 강조. 데이터 쌓이면 자동 재계산.

## 3. 섹터 점수
```
raw   = w_mom·C_mom + w_acc·C_acc + w_qual·C_qual + w_cyc·C_cyc   (결측 축은 가중제외 재정규화)
score = cross_sector_percentile( raw × confidence ) → −100 ~ +100
```

## 4. 기업 점수 — 두 렌즈 종합
```
E(수출)  = 기업 실측 수출 점수            (있으면; 이때 섹터수출은 중복이라 제외)
         = 섹터 수출 점수 × exposure       (없으면 폴백)
I(산업)  = 기업 산업 점수                  (있으면)
         = 섹터 산업 점수 × exposure       (없으면 폴백; 스텁이면 r_I=0)

score_company = ( r_E·E + r_I·I ) / ( r_E + r_I )       # 결측 렌즈 drop 재정규화
r = f_recency · f_length · f_direct
    f_recency = 1.0(≤2M) → 0.5(12M) 선형감쇄
    f_length  = min(1, n_months/24)
    f_direct  = 1.0(기업직접) / exposure(섹터폴백)
exposure ∈ 0~1 = HS_MAP 매칭 × (매출 내 수출비중, 있으면)
```
E·I 둘 다 있는데 크게 엇갈리면 **발산 플래그**.

## 5. 안전장치
1. **베이스효과**: |yoy|↑ + 전년 트로프 + ma3_yoy와 큰 괴리 → 플래그 + 감쇄.
2. **신뢰도 게이트**: 최신성·이력 길이·결측 → 점수 신뢰 하향.
3. **결측**: 항상 가중제외 재정규화(0 채우기 금지).

## 6. 출력 스키마
```
섹터: {sector_score, layers/axes{mom,acc,qual,cyc}, weights{...}, profile{ρ,π,σ}, confidence, flags[], insight}
기업: {company_score, export_part, industry_part|None, exposure, reliability{r_E,r_I}, flags[], insight}
```

## 8. 빌드 플랜 — Claude Code STEP별 명령 (하나씩 복사)

### STEP 0 — 스캐폴드/스키마
```
epsrev/trade_score/ 패키지와 dataclass 스키마만 생성(계산 X). 핸드오프 6·7절 스키마대로:
AxisSignals(mom,acc,qual,cyc), SectorProfile(rho,pi,sigma,weights), SectorScore, CompanyScore.
입력은 trade_utils_data.py의 compute_item_metrics·compute_company_metrics 결과(yoy,mom,price_yoy,volume_yoy,ma3_yoy,ma3_yoy_prev)를 재사용하도록 로더 연결만 확인. 읽었다고 알려줘.
```

### STEP 1 — 4축 원신호 (signals.py, 순수 함수) ★series_type 분기 필수
```
0) 전처리: 모든 시계열은 계산 전 '월간 리샘플'로 통일.
   - resample_monthly(series, how): 일/주 → 월(레벨=월말 or 월평균, growth·flow=월합계),
     분기/반기 → 월(ffill 또는 보간, 단 관측점만 유효 표시). config의 freq로 how 결정.
   - 리샘플 후에만 아래 축 계산(주기 혼재 시 YoY/차분 왜곡 방지).

1) series_type == "growth" (수출·판매·생산 등 '양'):
   - momentum = ma3_yoy
   - accel = ma3_yoy - ma3_yoy_prev ; trough_rebound = (ma3_yoy_prev<0 and ma3_yoy>ma3_yoy_prev) 강도
   - quality = f(volume_yoy, price_yoy): 물량우세 가점·단가우세 감점(volume_yoy - price_yoy 정규화)
   - cycle = runrate_gap = 최근값/24M평균 - 1

2) series_type == "level" (금리·유가·마진·스프레드·신조선가·BDI·단가·증감률·잔액·재고 등):
   - momentum = 레벨 변화. Δ = x_t - x_{t-1} (또는 3M: x_t - x_{t-3}), 스케일은 STEP 2의 z로 흡수.
     대안: 레벨 자체 z(self_history_z)로 '수준 위치'를 momentum 프록시로. → 기본은 Δ 사용.
   - accel = 레벨 2차 차분 = Δ_t - Δ_{t-1} = x_t - 2·x_{t-1} + x_{t-2}
   - quality = None  → 품질축 '가중 제외'(재정규화). 가격엔 물량/단가 개념 없음.
   - cycle = 레벨 vs 24M 추세 위치 = x_t / mean_24M(x) - 1 (growth의 runrate_gap과 동일식, 레벨에 적용)
   - ⚠️ level형에 YoY-성장률(ma3_yoy) 로직 쓰지 말 것 — 레벨의 YoY%는 왜곡.

raw 반환, 결측 None, 분모/길이 가드. quality=None이면 STEP 5 가중합에서 w_qual 제외 후 Σ=1 재정규화.
pytest: [growth] 성장/가속/물량주도/단가주도/저점반등/결측 ·
        [level] Δ모멘텀/2차차분가속/quality=None재정규화/YoY미사용/일·주 리샘플후 계산.
```

### STEP 2 — ① 자기 이력 표준화 (normalize.py)
```
self_history_z(hist_values, x) = clip((x - median)/MAD, -3, 3). MAD=median(|x-median|), 0이면 std 폴백/None.
각 축 raw를 그 시리즈 자기 이력으로 z화하는 래퍼.
- growth·level 공통: 각 축 raw(Δ·2차차분 포함)를 '그 축의 자기 이력' 분포로 z화 → 단위 상이(금리 %p vs 수출 십억$)를
  동일 스케일로. level의 Δ/2차차분도 Δ 이력의 median/MAD로 z화(레벨 원값이 아니라 '변화량'의 분포 기준).
- quality=None(level)은 z 대상에서 빼고, STEP 5에서 w_qual 재정규화로 처리.
pytest: 고변동/저변동 시리즈가 같은 스케일로 정규화 · level의 Δ가 변화량 이력 기준으로 z화되는지.
```

### STEP 3 — ② 섹터 특성 통계 + 자동 가중 (normalize.py)
```
sector_profile(sector_hist): rho=clip(autocorr(ma3_yoy,3),0,1), pi=Var(price_yoy)/(Var(price_yoy)+Var(volume_yoy)), sigma=MAD(ma3_yoy)를 전섹터 min-max.
auto_weights(rho,pi,sigma): 핸드오프 2절② 산식대로 w_acc/w_cyc/w_qual/w_mom 계산 후 Σ=1 정규화. 상수(0.6/0.5/0.8/0.3)는 모듈 상단 CONST로.
pytest: 사이클형(rho↑)→w_acc↑, 원자재형(pi↑)→w_qual↑, 변동↑→w_mom↓.
```

### STEP 4 — 신뢰도 + 베이스효과 (aggregate.py)
```
confidence(latest_m, n_months, missing_ratio) = f_recency·f_length·f_completeness (핸드오프 4절 감쇄식).
base_effect_flag(yoy, ma3_yoy, prior_yoy): yoy 급증 + 전년 트로프 + yoy와 ma3_yoy 큰 괴리 시 True. pytest.
```

### STEP 5 — 섹터 집계 (aggregate.py)
```
sector_score(axes_z, weights, confidence, cross_sector_raws): raw=Σ w·C(결측 가중제외 재정규화) → ×confidence → 전섹터 percentile → -100~100.
단일/배치(전 섹터) 지원. pytest(배치 여러 섹터/일부 축 결측/베이스효과 감쇄).
```

### STEP 6 — 기업 종합 (company.py)
```
company_score(export_lens, industry_lens): 
- E = 기업직접(있으면) else 섹터수출×exposure ; 직접이면 섹터 제외(중복방지)
- I = 기업/섹터 산업(스텁이면 r_I=0)
- score = (r_E·E + r_I·I)/(r_E+r_I), r=recency·length·direct(핸드오프 4절). 결측 렌즈 drop.
- exposure: HS_MAP 매칭×수출비중(없으면 기본 1.0 또는 0.5). E·I 발산 크면 flag.
pytest(직접/폴백/산업결측/발산/노출차등).
```

### STEP 7 — 인사이트 + 연동 + 검증
```
insight.py로 축 기여 기반 한 줄 인사이트+flags. 통합 스키마 반환.
기존 sc.d(calc_data_score)·대시보드 signal_score를 이 엔진으로 교체·통일 연동.
검증: 배치로 전 섹터 점수·대표 기업 점수가 합리적 범위인지, 베이스효과·발산 플래그·결측 재정규화 동작, 자동가중이 섹터별로 다르게 나오는지.
```

## 9. 반드시 지킬 것
1. 자기 이력 z → 섹터 특성 자동 가중 → cross-sector percentile 순서 준수.
2. 결측 None → 가중제외 재정규화(0 금지).
3. 기업 직접 수출 있으면 섹터 수출 중복 계산 금지.
4. 산업은 seam(r_I=0으로 v1 통과), v2에서 연결만.
5. 가속(C_acc)·자동가중이 이 스코어의 차별점 — 정확히 구현.
